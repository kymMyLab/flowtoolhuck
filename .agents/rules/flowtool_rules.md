# FlowTool 開発運用ルール

## 1. パッケージダウンロード設計（絶対規範・モーダル禁止）
- **ZIPパッケージダウンロード完了時に、ダウンロード用モーダル（`PackageDownloadModal`等）をポップアップ表示してはならない。**
- **理由**: ユーザーは複数のエピソードを一括・連続ダウンロードするため、モーダルが出現するとクリックを強いられ作業の流れが著しく阻害される。
- **仕様**: 完了時は自動的に直接ダウンロード（`savePackageFile`）を実行し、ログに完了を出力するのみとする。モーダルUIは永久廃止。二度と復活させてはならない。

## 2. デプロイ運用
- 変更後は必ず `npm run deploy` を実行し、Git コミット・GitHubプッシュ・jsDelivr CDN パージ・`MOUNT_COMMAND.js` 更新を一括で行うこと。
